# 提示词组织方案（Prompt Engineering）

## 核心判断

| 写法 | 主要控制 | 优点 | 风险 |
|------|----------|------|------|
| **情绪法** | 氛围、心理感受、叙事气质 | 灵活、自然、容易出惊喜 | 构图、光线、材质不稳定 |
| **结构法** | 主体、构图、光线、媒介、版式、约束 | 稳定、可复用、适合批量换角色 | 惊喜感少，容易模板化 |
| **混合法** | 结构锁结果 + 情绪补灵魂 | 稳定且有气质 | 需控制长度，避免重复 |

---

## 三种核心写法

### 1. 情绪法（管感觉）

先告诉模型"我要什么感觉"。

**示例：**
> 一个孤独又优雅的角色，站在午夜城市里，气氛神秘、怀旧，像一段被遗忘的旧电影。

**适合：**
- 风格探索
- 氛围先行的画面
- 想保留模型自由发挥时
- image2 这类更能吃自然语言气质的实验

**注意：**
- 情绪词不能替代画面锚点，发散时需补主体/构图/光线
- 同一段不要堆太多相近情绪词（"孤独、忧伤、破碎、绝望"同时出现会稀释方向）

---

### 2. 结构法（管画面骨架）

直接告诉模型"用什么视觉手段做出结果"。

**示例：**
> {角色}，复古黑色电影 + Art Deco 杂志封面，左前方 45 度主光，Kodak Tri-X 400 黑白胶片质感，顶部标题，底部签名。

**适合：**
- 批量换角色
- 封面、海报、包装、角色设定板
- 需要锁定摄影、光线、版式、材质时
- Nano Banana 这类更适合契约式控制的任务

**注意：**
- 结构项越多，越要删除低信号描述
- 摄影参数要服务可见结果，不要变成无意义堆词
- 固定模板连续使用时，要主动替换风格底座/光线/媒介，避免同质化

---

### 3. 混合法（实战默认写法）

先用结构锁住画面，再用一句情绪补气质。

**推荐顺序：**
1. 主体与身份
2. 风格或媒介
3. 构图与光线
4. 材质与画质
5. 情绪语感

**示例：**
> {角色}，复古黑色电影 + Art Deco 杂志封面，左前方 45 度主光，Kodak Tri-X 400 黑白胶片质感，旧杂志印刷纹理。整体气氛克制、神秘，像午夜后才会出现的一期私人刊物。

---

## 九种辅助写法

| 方法 | 核心 | 适合场景 |
|------|------|----------|
| **结果法** | 直接描述最终画面长什么样 | 快速直出，细节稳定性弱于结构法 |
| **过程法** | 按拍摄/制作/后期过程来写 | 锁摄影、布光、材质和工艺流程 |
| **参考法** | 用时代/媒介/流派/类型作为审美锚点 | 快速定调，参考对象要少而准 |
| **变量模板法** | 把角色/风格/场景/光线做成可替换槽位 | 批量生产、系列测试、角色替换 |
| **约束法** | 重点写边界和不可接受结果 | 防跑偏，不能单独承担主画面生成 |
| **叙事法** | 给画面一个隐含故事，让主体和场景更有张力 | 角色海报、剧照、封面、系列世界观 |
| **媒介法** | 先锁作品载体和质感 | 控制摄影/绘画/版画/杂志/档案照/包装等视觉载体 |
| **设计系统法** | 把画面当成版式系统来写 | 封面/海报/包装/UI/信息图/图文混排 |

---

## 实战建议

| 场景 | 推荐组合 |
|------|----------|
| 快速试风格 | 情绪法 + 参考法 |
| 批量换角色 | 结构法 + 变量模板法 + 约束法 |
| 封面和海报 | 结构法 + 媒介法 + 设计系统法 |
| 稳定又不僵硬 | 结构法 + 情绪法 + 媒介法 + 约束法 |
| 跨模型复用 | 先保留共享视觉语义，再按目标模型改写语气和颗粒度 |

## 快速归类

```
情绪法 → 管感觉
结构法 → 管画面骨架
结果法 → 管最终成品
过程法 → 管怎么拍/怎么做
参考法 → 管审美锚点
模板法 → 管复用
约束法 → 管不跑偏
叙事法 → 管故事张力
媒介法 → 管质感
设计系统法 → 管版式层级
```
