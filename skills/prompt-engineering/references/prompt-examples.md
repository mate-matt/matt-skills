# 提示词方法论实战参考

## 三种核心写法的prompt对照

### 情绪法示例

```
一个孤独又优雅的角色，站在午夜城市里，气氛神秘、怀旧，像一段被遗忘的旧电影。
```

### 结构法示例

```
女性角色，复古黑色电影 + Art Deco 杂志封面，左前方 45 度主光，Kodak Tri-X 400 黑白胶片质感，顶部大标题，底部艺术家签名。
```

### 混合法示例

```
女性角色，复古黑色电影 + Art Deco 杂志封面，左前方 45 度主光，Kodak Tri-X 400 黑白胶片质感，旧杂志印刷纹理。整体气氛克制、神秘，像午夜后才会出现的一期私人刊物。
```

## 九种辅助写法prompt对照

### 结果法
```
一张复古杂志封面，中央是一位黑衣侦探，顶部有大标题，整体像旧电影海报。
```

### 过程法
```
用中画幅胶片相机拍摄，左前方柔光箱打光，后期保留胶片颗粒和纸张印刷质感。
```

### 参考法
```
1930s Art Deco 杂志封面，黑色电影摄影，Kodak Tri-X 黑白胶片。
```

### 变量模板法
```
{{character}}，{{style}}杂志封面，{{lighting}}，{{material}}，底部签名 {{signature}}。
```

### 约束法
```
避免赛博朋克、避免卡通、避免现代手机海报感、避免文字乱码。
```

### 叙事法
```
像午夜档案里被重新发现的一期杂志封面，角色刚从一场秘密会面中归来。
```

### 媒介法
```
真实旧杂志扫描图，纸张纤维、印刷网点、轻微褪色边缘。
```

### 设计系统法
```
顶部大标题，左右栏目文字，底部小号签名，版式克制、留白清晰。
```

## 古风仙侠角色示例

### 夜琉璃（合欢宗圣女）

```
夜琉璃，古风仙侠角色立绘，合欢宗圣女造型，红色渐变薄纱长裙，精美银色发饰，左侧45度侧光，薄纱半透明质感，暗色背景低角度仰视。整体高冷、交易型气质，眼眸透着一丝算计与精明，像在审视一场等价交换。
避免：现代感、卡通感、过度柔光
```

### 小棠（前朝遗孤/天灵根）

```
小棠，古风仙侠角色立绘，大长老女儿造型，冰蓝色丝绸长裙，银白长发及腰，发间有冰晶发簪，正面居中光源，冰属性灵力特效带霜雾感，背景虚化。整体软糯、温柔但眼底藏着隐忍，像一朵被雪藏的梅花。
避免：火属性、暖色调、攻击性姿态
```

## 跨模型适配参考

### Nano Banana（契约式/结构化）
- 多用结构法 + 约束法
- 参数要明确、具体
- 避免模糊情绪词

### GPT-image / gpt-image-2（理解型）
- 多用混合法 + 情绪法
- 可以更自然、更有叙事感
- 适当保留模型自由发挥空间

### Midjourney（探索型）
- 情绪法 + 参考法效果更好
- 风格锚点要少而准
- 让模型在框架内自由探索
