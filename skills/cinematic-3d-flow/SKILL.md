# Cinematic 3D Flow

先理解主题，再决定空间、机构和镜头。交付可离线打开的单一 HTML；题材、品牌、配色、拓扑和机械形态全部来自本次请求，不继承其他任务。

## 1. 先拆主题，不能先画八爪鱼

阅读用户提供的资料；有代码或图表时，从实际关系提取节点和边。稳定的一般知识可以直接用于概念展示；遇到陌生机制、实时部署、具体产品版本或需要出处的事实时，使用可用搜索工具查一手来源。没有搜索工具时记录未确认项，不冒充已验证。

在开始美术和代码前，给出一份简短结构拆解：

- 展示对象：观众需要理解什么，输入和输出是什么。
- 实体与层级：核心对象、参与者、支撑资源；真实包含关系与实例关系。
- 流程：有向边、先后/并行、反馈/持久化、业务结果。
- 证据：资料明确的事实、一般知识、仅为展示采用的假设。

将详细结果记入项目的 `scene-spec.json`，结构见 [主题与场景契约](references/structure-and-spec.md)。明确区分业务流程、技术调用和基础设施包含关系；示意实例数不能作为当前运行状态。

只在关键关系缺失时询问用户。其余缺失项用显式假设继续。不要把抽象概念擅自替换成部署架构，也不要把依赖关系画成数据经过的管道。

## 2. 决定形态与播放约定

依据拓扑选形态：中心协调型可用分节机械臂；串行流程可用装配线；循环机制可用环轨；分层系统可用堆叠平台。八条机械臂是一种选项，不能为了凑八条边虚构实体。

先读 [镜头与播放](references/camera-and-playback.md)。记录以下设置，用户已给出的值优先：

| 设置 | 未指定时的起点 |
| --- | --- |
| 镜头 | `overview-orbit → hero-dolly → cluster-cut → flow-follow`，四镜头 |
| 转场 | 镜头间 `cut`；每个镜头内部缓慢移动 |
| 周期 | 7 秒，自动重播 |
| 暂停 | 空格切换；显式播放/暂停按钮可关闭，背景模式默认不常驻 |
| 自动暂停 | 页面隐藏时冻结所有时钟，回来继续 |
| 减少动态 | 停在可读总览；只有明确操作才继续播放 |
| 风格 | 根据本次品牌/参考选择；没有参考时用中性浅色、深色关节、一种强调色 |

可选运镜包括环绕、推进、横移、升降俯瞰、目标切换、沿边跟随、机构微距和整台转台。需要用户选择时，一次给 2–3 套组合即可，不让用户配置整个引擎。用户未回复可采用上述起点，不把可选讨论变成审批流程。

## 3. 空间与画面

先做可读静帧，再做运动。保留主舞台的视觉优先级，文字只承担节点名、必要关系和当前镜头。没有要求时不添加副标题、解释段落或虚构遥测。

工业控制台布局可用中央大主体、两侧紧凑面板、细分隔线与单色状态标记；纯背景模式则隐藏常驻控制台。面板必须描述真实结构或当前演示进度，不能假装是在线监控。

为每个镜头定义需要看清的节点和保留区。近景允许裁掉非重点外围，但不能用侧栏挡住当前目标。文字位置跟随 3D 投影；必要 UI 留在独立安全区域。小屏隐藏次要面板，保持核心对象和播放可用。

## 4. 实现

读 [实现与资产](references/implementation.md)，再按所需分支实施。可从通用模板起步：

```bash
node <skill-dir>/scripts/scaffold.mjs <absolute-project-dir>
cd <absolute-project-dir>
npm install
npm run build
```

模板提供不涉及具体产品的水循环合成示例；先替换 `scene-spec.json`，再修改造型，不能直接交付示例充当用户主题。若环境已装有兼容依赖，可复用依赖，不重复下载。其他包管理器也可用。

- Three.js：场景、相机、几何与实例化机构。
- Canvas：高清文字贴图、淡网格/电路纹、接触阴影。
- SVG：可选 logo、图标或线稿；真实 3D 主体和关节用几何体构建。
- 图像生成：仅在缺少必要美术资产时使用；优先保留现有矢量，不为“高清”重绘品牌。
- 一个主时钟驱动相机、流粒子、机构和 HUD；暂停必须冻结它们全部。

模板是实现起点，不是固定主题或固定画风。机构、边路径和分镜应随主题修改。

## 5. 打包与验证

构建脚本将 JavaScript、库、CSS、配置及所选本地资产内嵌，生成 `dist/scene.html`。不依赖 CDN、远程字体、外部 JSON、动态 import 或本地相邻文件。第三方许可证内嵌 HTML 注释。

使用项目的浏览器工具优先验证；可直接执行模板的验证脚本：

```bash
npm run verify
```

必须核实：

1. `file://` 打开后有真实渲染，无外部网络请求、脚本报错或不完整 logo。
2. 不同镜头构图明显不同；“切镜”是离散构图变化，不是亚像素摆动。
3. 机构端点/关节实际位移；粒子沿正确方向；所有时钟可暂停并恢复。
4. `t=0` 与 `t=duration` 的全场状态相同；检查最后一小段到开头的实际转场。硬切循环与无缝连续循环是两种约定，不能混称。
5. 桌面、小屏、减少动态、恢复前后台及键盘均可用。镜头切换允许设计性的取景裁切，不要求近景包含所有节点。

验证细节和常见失误见 [验证台架](references/verification.md)。只报告已做的检查；软件渲染的自动截图不能证明真实设备帧率。
