# 验证台架

## 可观测接口

模板暴露：

- `window.__scene.seek(seconds)`：暂停并精确渲染，所有时钟一起定位。
- `window.__scene.play()` / `.pause()`：明确设置状态，不是 toggle。
- `.state()`：当前时间、播放/可见状态、镜头编号、相机位置、机构端点、关系图和渲染统计。

自动测试通过显式 pause/play；用户界面按钮才 toggle。若测试先 focus 了“镜头按钮”再按空格，该按钮的默认激活也可能触发播放；处理键盘时应检查事件目标，避免切镜点击副作用，不能靠扩大超时掩盖。

## 核验顺序

1. 使用 `file://` 加载成品，监听 script error 和网络请求。确认画布非空，不是 fallback 冒充 3D。
2. 截取每个镜头中段，并在切镜点前后取样。对比相机位置/目标/景别；实际看截图是否选中了重点。
3. 读取两个不同时间的所有 arm tips，打印实际位移。固定总时长后测首尾周期，不能用截图“看起来在动”代替。
4. 暂停前后等待短时间，检查 elapsed、相机、关节、HUD 一致。恢复应只推进等待后的播放时间；隐藏/恢复不得解除手动暂停。
5. 验证 loop 和 once 两种策略；loop 要检查 `duration-ε` 与 0 的转场是否符合 cut/continuous 约定。once 的最后一帧必须保留最后镜头而非跳回第一镜头。
6. 检查 375px 与桌面、长节点名、200% 缩放、键盘、减少动态，以及无 WebGL/无 JS fallback。
7. 检查图中实际边与主题证据一致，包含关系和单向调用没有被机械臂装饰改写。

每条 oracle 应对应一个实际要求，不计算混合“质量分”。静帧美感、文字遮挡和当前镜头重点仍需人工看截图。

## 常见错误

| 症状 | 处理 |
| --- | --- |
| 浏览器画面只有备用 logo，探针却存在 | 检查 context loss 和 fallback 可见性；不要只读 draw-call 计数 |
| 画面发灰 | 基础地面/UI/logo 关闭不需要的 tone mapping；灯光服务于主体 |
| 所谓运镜只有轻晃 | 给镜头不同 focus 和尺度，明确切换边界；正交 dolly 改 span |
| 标签漂移/遮住节点 | 按世界位置投影；改本镜头构图或标签偏移，不写死屏幕百分比 |
| 暂停后关节还动 | 去掉独立时钟、CSS animation、绝对时间和累积旋转 |
| 自动截图首尾一样但循环仍跳 | 0 和 duration 本来是同一取模时刻；额外检查末尾邻帧和剪辑约定 |
| once 结束时跳回总览 | 对 end 状态用 duration-ε 评估最后镜头，显示时钟仍可为 duration |
| 媒体偏好测试超时 | 等待 matchMedia change 后读状态；检查按钮默认激活和 held time；不要盲目重试 |
| PNG/HTML 之外还有运行附件 | 重新打包所有依赖，再独立复制 HTML 到空目录打开 |
