# 机构、资产与单文件打包

## 几何分工

机械机构不需要用大量 SVG 或生成图伪装深度：

- 核心：球体/圆柱组合，外壳与深色底座对比；纬线、板缝、环带和小铆钉控制尺度感。
- 分节机械臂：Catmull-Rom 曲线 → 相邻采样点 → 朝向对齐的圆柱骨架、短白色套筒、深色球关节和强调色轴环。
- 节点：圆角挤出底座、叠层、磁盘/柱体、卡片等少量可区分体块。造型帮助辨认语义，不只是随机装饰。
- 机械臂目标数按语义决定；其端点可收缩/卷曲，实际流边仍独立且方向明确。

同一类关节、套筒、轴环使用 InstancedMesh。每帧只更新矩阵；几何与材质在初始化创建。动态实例包围盒可能过期，可关闭这些少量批次的 frustum culling，或按实际外廓更新包围盒。避免给几百个小零件都启用实时阴影。

沿曲线两点 a、b：中点为 `(a+b)/2`，长度为 `|b-a|`，四元数将几何默认 Y 轴对齐 `normalize(b-a)`。套筒长度缩短一点，露出深色关节。长度为零时跳过该段，防止 NaN 四元数。

收缩用沿目标方向的 reach；卷曲用垂直侧向量、周期相位和末端控制点。函数以完整循环相位为输入，不能在每帧累加旋转。机构活动要随流程变化，不能遮住当前镜头关键节点。

## Canvas 与 SVG 的位置

Canvas 可生成 2× 分辨率文字贴图、淡透视网格、线路节点和径向渐变接触阴影。文本贴图设置 SRGB，显示材质禁用 tone mapping，避免深色字被映射成浅灰。阴影贴图关闭深度写入，放在地面上方，减少排序/Z-fighting。

SVG 适合已有 logo、图标、工程线稿。优先使用用户源矢量；低清位图不会因为转存 SVG 就变高清。栅格贴图按近景投影尺寸准备；不要在近景放大低清截图。

logo 装在球体前面时，badge、图片和边框必须都位于球面最前沿之外。只把图片放到“圆形镜框前”，可能仍被球壳挡住上半部分。每个侧镜头都检查可见性和透明排序。

## 单文件

模板的 `build.mjs` 用 esbuild 打包 Three.js 和入口；将配置及本地 logo 内嵌，再把 CSS 与 bundle 放入模板。许可证文件写入 HTML 注释。

- 构建期可装依赖；最终交付离线运行。
- 构建前检查 PNG/SVG/WebP 等 MIME，拒绝远程 logo URL，使用本地用户授权素材。
- 使用函数式 `String.replace` 注入文本，避免 `$&` 等替换占位语义破坏 JavaScript。所有 `</script` 转义；注入标题/属性时转义 HTML。
- 不留相对路径、CSS `url()` 外链、fetch、运行时 import、远程字体或 sourceMappingURL。
- scene-config 和通用模板是工作源，不是最终运行所需附件。

## 性能与失败处理

一个 rAF，DPR 上限 2；避免每帧重建纹理/材质。必要时减少曲线采样、关节段数和球体分段。浏览器截图软件渲染慢时，不能据此改成没有验证过的另一套渲染方案。

初始化 WebGL 失败或 context lost 时显示内嵌静态示意与可读节点名。没有 JS 时仍显示主题和备用图。优先用现有浏览器工具验证；不要为了验证而改用户系统 GPU/安全设置。
