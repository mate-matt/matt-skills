# 镜头与播放策略

## 镜头菜单

模板支持以下 `preset`；同一主题可混搭。名字是可配置选项，不是把每种运镜都塞进一段短片的要求。

| preset | 可见变化 | 适用目的 | 建议节奏 |
| --- | --- | --- | --- |
| `overview-orbit` | 全场缓慢环绕，平台侧面与遮挡改变 | 建立拓扑 | 1.5–3 秒 |
| `hero-dolly` | 推向核心，同时降低视角 | 强调主体与机构 | 1–2 秒 |
| `truck` | 横向移动，前后层产生视差 | 比较并列流程 | 1.5–3 秒 |
| `crane` | 从侧上方升向俯瞰 | 看清层级/汇聚 | 1.5–3 秒 |
| `cluster-cut` | 切至 focus 节点群，近距离侧视 | 支撑系统/分支特写 | 1–2 秒 |
| `flow-follow` | 相机目标从源向目的平移 | 展示传输过程 | 1–2 秒 |
| `turntable` | 单个对象周围较大幅旋转 | 展示几何、关节、背面 | 3–6 秒 |
| `static` | 固定相机 | 背景/可访问静态版 | 按阅读需要 |

正交相机的推进需要同时缩小 `span`，只沿视线移动相机不会变大。透视相机可用真实 dolly，但避免广角导致文字和尺寸失真。`flow-follow` 的 focus 前两项决定跟随方向；没有第二项时只缓慢横移。

## 三种组合

- 清爽背景：总览环绕 + 轻横移；6–10 秒；没有常驻 UI，空格可暂停。
- 工业机构展示：总览 → 低机位核心推进 → 子系统侧切 → 流程跟随；5–8 秒；硬切与短促运动结合。
- 讲解/审阅：俯瞰 → 关键步骤 → 反馈/回收 → 全局；10–20 秒；可见暂停按钮，留阅读时间。

每个镜头规定目标、进入姿态、退出姿态、持续时间和边界。镜头内部只使用一次缓动；不要给时钟和轨迹同时加缓动。避免相机环绕时标题漂移：节点标签用 3D sprite 或每帧投影，固定 UI 在安全区域。

## 真正的切镜

`cut`：镜头边界直接换位置、目标和取景尺度；镜头内部继续运动。可用短细线/闪标提示剪辑，但不需要白屏或渐隐。

`continuous`：相邻镜头的退出和进入姿态连接，插值位置、target、span。最后一镜也要接回第一镜。不能在连续相机外再叠一个追随 lerp，否则 seek 结果依赖播放历史。

“强烈”应来自明显不同的角度、焦点和景别，而不是每帧抖动、持续眩光或高速 360° 旋转。

## 一个播放状态机

维护 `elapsed`、`playing`、`lastNow`。暂停后不更新 elapsed；恢复把 lastNow 清空，避免把停留时间算成跳帧。前后台恢复只恢复先前正在播放的状态，不能顺带取消用户暂停。

所有运动只使用 `renderAt(time)`：相机、关节、粒子、灯、HUD、进度和 UI 状态。禁用独立 CSS 动画、Date.now 或自行递增的对象旋转，避免暂停“只停一半”。

边界规则：

- loop: `t = ((elapsed % duration) + duration) % duration`。
- once: `t = min(elapsed, duration)`；渲染最后一帧，进入停止状态，播放按钮可从头再播。
- 默认隐藏页面不推进时间；用户也可明确要求回来从头播。
- 减少动态先渲染安全总览并停住；UI 清楚显示当前没有播放。
- resize 仍使用 held time 或当前 elapsed，不能把测试 seek 重置成零。

选择“连续无缝”时，位置、关节、相机、透明度和 HUD 都应周期一致。选择“剪辑循环”时，允许末镜硬切到总览，但要如实说明，不能以 `renderAt(0)==renderAt(duration)` 冒充肉眼没有切镜。
